# On the Efficacy of Heterogeneous Draft Models for Training-Free Speculative Decoding

This repository contains the code and datasets used in our study on evaluating the efficacy of heterogeneous draft models for training-free speculative decoding.

## Quick Run

For Mamba as drafters, run this command:

```bash
sbatch scripts/mamba.sh
```

## Adknowledgement

Our code is built on this project: https://github.com/hemingkx/Spec-Bench; which can also be cited as: Xia, Heming, et al. "Unlocking efficiency in large language model inference: A comprehensive survey of speculative decoding." Findings of the Association for Computational Linguistics: ACL 2024 (2024): 7655-7671.
